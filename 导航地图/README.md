# 导航地图 —— 赛道中心线（给惯导用）

> 来源：B 车（test16）从 `赛道图-原件-5000x5000-黑底白线.png` 自动提取的赛道中心线。
> 用途：给小车**惯导（里程 + 航向 + 已知几何）**当"已知赛道几何"用：查当前位置、算前瞻、判元素、做地标重置。

## 文件

| 文件 | 说明 |
|---|---|
| `赛道图-原件-5000x5000-黑底白线.png` | **原件**（5m×5m 场地 CAD 图，25mm 白线；含尺寸标注） |
| `赛道中心线-预览.png` | 提取结果叠加在原件上（红线=中心线，绿短线=行进方向，**蓝方块=发车点**）——**先看这张确认** |
| `赛道中心线-mm.json` | 路点数据（**10mm** 间隔，3710 点，全精度；含 s / x / y / yaw / R） |
| `nav_map.h` | 直接 `#include` 的 C 表（**50mm** 间隔，742 点，占 Flash ≈ 14.5KB） |
| `赛道图转惯导地图.py` | 生成脚本（只用 numpy+PIL；改间隔/标定/发车点都能重跑） |

## 关键数

| 项 | 值 | 怎么来的 |
|---|---|---|
| 比例 | **5.8005 mm/px** | 场地外框 862px = 5000mm；再用 E 区 R300 圆（109px 外径 = 625mm）交叉验证 |
| 单圈周长 | **37.11 m** | 沿中心线累计（闭环） |
| **s=0** | **发车点**（2772, 203）mm | S-G 两线**净空中点**（S 线中心 x≈2546、G 线 x≈2998，净空 400mm） |
| **行进方向** | **车头朝 S ⇒ 顶直线沿 −X** | 由用户给定；s 递增 = 真实跑向 |
| 自检 | 最大单步跳变 **98.6mm**（限 100）✓；E 区之外骨架覆盖 **100%** ✓ | 脚本每次重跑自动打印 |

## 坐标系（**必须一致，否则越导越偏**）

```
原点 = 场地左上角
X    = 向右为正（mm）
Y    = 向下为正（mm，与赛道图同向）
yaw  = 0° 指向 +X；顺时针为正（因为 Y 向下）
R    = 曲率半径 mm；直线段填 1e9
s    = 从发车点起算的累计弧长 mm，递增方向 = 真实跑向
```
⚠ 若用 **Y 向上 / 逆时针为正** 的右手系：`y` 取负、`yaw` 取负即可。

## ★E 区（4 个相切圆）—— 地图与实物线不一样，**这是故意的**

实物/原图在 E 区画的是 **4 个完整的外切圆**（R300）。但**车不能绕整圆**（会死循环）：

- 每个相切点物理上是"**四臂交汇**"，**纯灰度质心解不出来**（两条分支几何上完全对称）；
- 正确过法是**在每个相切点换圆**，于是实际路线是一条**蛇形**（每个圆只走半边）。

地图里编的就是这条蛇形：

```
进 E（自 D 区）→ 第4圆右半 → 第3圆左半 → 第2圆右半 → 第1圆左半 → 出 E（第1圆顶点向上）
```

所以地图在 E 区**只覆盖每个圆的一半**；另半边是"车不走的分支"，覆盖率统计里已把 E 区排除
（全区 630 个未覆盖点全在 E 区，属设计预期）。

⚠ **固件侧**：到 E 区前必须**靠里程/航向**决定切换，不能靠灰度；建议做一个圆环状态机
（"进 E 区 → 数到第几个切点 → 切到下一个圆"）。

## 怎么用

**固件（C）**
```c
#include "nav_map.h"
/* NAV_MAP[NAV_MAP_N]：按 s_mm 二分查表，或按 (x,y) 找最近点 */
nav_pt_t p = NAV_MAP[i];
```

**上位机 / 脚本**
```python
import json
m = json.load(open("赛道中心线-mm.json", encoding="utf-8"))
pts = m["pts_mm"]        # [[x_mm, y_mm], ...]
yaw = m["yaw_deg"]       # 逐点航向
R   = m["radius_mm"]     # 逐点曲率半径（直线为 null）
```

## 限制（老实说）

- 从 **CAD 截图**自动提取，不是测绘；**弯道中心线有 ±2~3mm 量级抖动**（像素+细化固有），
  循迹够用，**别当毫米级基准**。
- 比赛实际赛道布与 CAD 图可能有铺装误差 → 实跑要用**地标（十字/斑马线）重置**吸收。
- 脚本每次重跑都会打印两条自检（最大跳变 ≤100mm、E 区外覆盖 100%）；**改完务必看预览图**。

## 怎么重生成

```bash
python 赛道图转惯导地图.py <赛道图.png> <输出目录>
```
脚本只用 `numpy + PIL`（无需 cv2/scipy）。流程：阈值 → 形态学开运算（去标注/文字/外框）
→ 取最大连通域 → Zhang-Suen 细化 → 带方向行走（路口按"与来向相反的转向"选分支 = 相切点换圆）
→ 漏走弧补接（连接 >100mm 一律不接）→ **E 区按拟合圆解析重建** → 方向校正 → s=0 挪到发车点
→ 自检 → 等弧长重采样 → 出 JSON / C 表 / 预览。

换赛道：改脚本里的 `FIELD_PX`（外框像素范围）与 `START_X_MM/START_Y_MM`（发车点）即可。
